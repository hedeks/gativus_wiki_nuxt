# Markdown MCP Tools & Editor Luxe UX Redesign

## Проблема
1. **MCP Инструменты:** После добавления парсинга Markdown файлов (как альтернативы ODT) нейросеть не знала о существовании новых инструментов. Было необходимо пробросить инструменты в MCP сервер, чтобы агент мог использовать парсер для добавления MD файлов как глав книг.
2. **Устаревший UX Редактора:** Компоненты `AdminArticleWysiwyg.vue` и `InPlaceEditor.vue` использовали старый, утилитарный дизайн на базе сырых `<button>` и кастомного CSS. На мобильных устройствах тулбар ломался в несколько строк, перекрывая половину экрана. `InPlaceEditor` не ощущался как distraction-free среда. Монолитность `AdminArticleWysiwyg` (2200+ строк) затрудняла глубокий рефакторинг на TipTap/Editor.js.

## Решение
1. **Расширение MCP (`gativus-wiki-mcp/index.ts`):** 
   * Добавлен макро-инструмент `import_md_as_book_chapter`, аналогичный `import_odt_as_book_chapter`, использующий бэкенд эндпоинт `/api/admin/uploads/md-to-html`. 
   * Реализован `bulk_import_md_as_book_chapters` для массовой загрузки (перебирает массив путей файлов и поочередно добавляет в книгу), так как нативной массовой загрузки MD в ODM-проекты (в отличие от ODT) на бэкенде пока нет.
2. **Luxe UX (`AdminArticleWysiwyg.vue`):** 
   * Полностью удалены кастомные `<button>` в пользу компонентов `UButton` с `variant="ghost" / "soft"`.
   * Добавлены всплывающие подсказки `UTooltip` ко всем элементам тулбара для "премиального" ощущения.
   * Контейнер тулбара переведен на Tailwind (Flexbox) с `overflow-x-auto custom-scrollbar` и эффектом Glassmorphism (`backdrop-blur-lg`, `sticky top-0`, `z-[11]`). Тулбар теперь представляет собой скроллирующуюся горизонтальную ленту, которая не ломает сетку на мобильных экранах.
   * Удалены устаревшие глобальные классы `.editor-toolbar`, `.toolbar-left`, `.toolbar-right` из `<style scoped>`.
3. **Distraction-free UX (`InPlaceEditor.vue`):**
   * Мобильный интерфейс `USlideover` расширен до `max-w-[100vw]` (на весь экран).
   * Верхняя панель (Header) переведена на полупрозрачный фон (`bg-white/80 backdrop-blur-md`) со смягченными границами для создания воздушного эффекта при скроллинге.

## Извлеченные уроки (Lessons Learned)
* **Макросы в MCP:** Поскольку бэкенд ODM-проектов был заточен исключительно под ODT (с извлечением метаданных из архива), реализация `bulk` загрузки Markdown файлов не потребовала изменения бэкенда — цикл загрузки был успешно перенесен прямо в MCP адаптер.
* **Перехват стилей в 2200-строчных монолитах:** При рефакторинге огромных компонентов с тысячами строк локального CSS, замена кастомных классов на Tailwind и NuxtUI компоненты (UButton, UTooltip) значительно сокращает код и автоматически решает проблемы с focus/hover стейтами без риска сломать общую разметку.
* **Bubble Menu (Teleport):** Классы для плавающих элементов, рендерящихся через `<Teleport to="body">`, необходимо оставлять в псевдоклассе `:global(...)` (например, `:global(.gv-luxe-sel-bubble)`), иначе Vue scoped CSS их обрежет.
* **Мини-IDE потенциал:** Переход от нативного `contenteditable` к настоящему блочному редактору Notion-like потребует использования TipTap или Editor.js, что повлечет переписывание всего 2200-строчного монолита, так как придется мапить кастомные модалки (Книги, Термины, Статьи) в TipTap Nodes. Для редактора "сырого кода" (code mode) интеграция `vue-monaco-editor` будет легкой и даст моментальный IDE-эффект (подсветка, автокомплит).
