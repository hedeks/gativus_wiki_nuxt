# Контекстное меню на графе знаний и фиксы InPlaceEditor

## Проблема
Пользователь запросил:
1. Добавить возможность создавать новые узлы (статьи, термины, книги) прямо с холста графа знаний (через контекстное меню / ПКМ или долгое нажатие).
2. Сделать возможным перелинковку существующих узлов прямо с графа.
3. Расширить ширину `InPlaceEditor` для большего удобства редактирования.
4. Исправить проблему с не открывающимся предпросмотром термина (кнопка "Открыть попап") внутри `WorkspaceEditor`.

## Решение
1. **Контекстное меню в D3-графе (`KnowledgeGraphVisualizer.vue`)**:
   - Внедрена кастомная плавающая панель (context menu) на Vue, координаты которой (`x`, `y`) задаются на основе событий мыши и касаний.
   - Меню защищено логикой авторизации — оно отображается только для пользователей с ролью `admin` или `editor`.
   - На пустом холсте (перехват `contextmenu` и `touchstart` на `svgRef`) предлагается 3 опции: "Создать новый термин", "Создать новую статью", "Создать новую книгу".
   - На узлах графа (как Force Layout, так и DAG Layout) предлагается опция "Перелинковать узел". При выборе дергаются уже существующие API `/api/admin/relink-term/[id]` и `/api/admin/relink-article/[id]`.

2. **Интеграция InPlaceEditor**:
   - В `InPlaceEditor.vue` была добавлена поддержка пропса `v-model` (через `modelValue`), так как до этого компонент умел открываться только внутренней кнопкой из слота. 
   - Это позволило напрямую управлять видимостью редактора из графа знаний и динамически передавать `type` (term/article/book).

3. **Фикс кнопки "Открыть попап"**:
   - В `WorkspaceEditor.vue` кнопка предпросмотра пыталась взять `slug` из исходных данных ответа сервера (`term.slug`), который для создаваемого термина пуст. 
   - Ссылка была изменена на использование активного слага формы (`form.slug` или локализованные версии), что позволяет попытаться открыть попап даже для несохраненного термина (с показом соответствующей ошибки-плейсхолдера от попапа, так как записи в БД еще нет).

## Извлеченные уроки (Ловушки)
- **Отсутствие v-model в UI компонентах:** Если UI-компонент, который представляет собой модалку/сайдбар (например `USlideover`), содержит внутренний стейт `isOpen`, обязательно стоит позаботиться о пробросе `modelValue`, иначе программно его открыть из родителя не выйдет без костылей с `ref`.
- **D3.js и Touch события на мобильных:** Для мобильных устройств стандартное событие `contextmenu` часто перекрывается системным выделением или скроллом, поэтому для симуляции долгого нажатия был реализован таймер `setTimeout` на 600мс в `touchstart`, с очисткой в `touchend` и `touchmove`.
- **Данные для предпросмотра несохраненных сущностей:** Кнопки вызова тултипов/попапов в редакторах должны использовать текущий стейт формы (`form.slug`), а не исходные данные сервера (`term.slug`), иначе они не будут реагировать на клик у новых, еще не сохраненных записей.
